# 🚀 유튜브 구간 반복 & 북마크 앱

이 프로젝트는 단일 HTML 파일로 구성된 가벼운 유튜브 생산성 웹 앱입니다.

## 🛠 기술 스택 및 주요 기능
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **API 연동:** YouTube IFrame Player API
* **데이터 보관:** 무거운 백엔드 서버나 외부 데이터베이스(Google Sheets 등)를 연동하지 않고, 사용자 브라우저의 **Local Storage**를 활용하여 데이터를 영구 보존합니다. 이는 개인정보 보호에 유리하며 응답 속도를 극대화합니다.
* **공유 시스템:** CSV 파일 내보내기/불러오기를 통해 다른 기기나 사용자와 직관적으로 목록을 공유할 수 있습니다.

## 💡 개발 히스토리 및 Next Step
* 초기 단순 구간 반복기에서 시작하여 북마크 및 CSV 공유 기능이 추가되었습니다.
* **한계점 인식:** 모바일 웹 환경(PWA)에서는 타 앱(유튜브 앱)으로부터 네이티브 공유 인텐트를 부드럽게 받아오기 어렵다는 점을 확인했습니다.
* **추후 계획:** 더욱 고도화된 모바일 사용자 경험(UX)을 위해, 본 프로젝트를 갈무리하고 **React Native** 기반의 네이티브 스마트폰 앱으로 별도 개발을 진행할 예정입니다.
